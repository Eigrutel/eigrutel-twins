## Français

Twins rejoint Eigrutel Lab : une application Windows pour repérer les doublons d’images, comparer deux aperçus et mettre les copies de côté.

- Doublons exacts et images visuellement proches de même définition.
- JPEG, PNG, WebP, TIFF, BMP et GIF ; sous-dossiers en option.
- Navigation par groupes, aperçus orientés selon les données EXIF.
- Dossier de destination personnalisable, déplacements vérifiés sans écrasement.
- Traitement des doublons exacts : conserver le plus récent, le nom le plus court ou le plus long.
- Interface et manuels FR/EN, arrêt des traitements et journal local.

**Windows :** téléchargez `Twins-1.0.0.exe` ci-dessous. Python n’est pas nécessaire.

Les fichiers écartés sont déplacés, sans réencodage. Une ressemblance visuelle doit être vérifiée ; elle ne prouve pas que les fichiers sont identiques. Pas d’annulation automatique des déplacements. Fonctionnement local sans compte ni collecte.

## English

Twins joins Eigrutel Lab: a Windows application for finding duplicate images, comparing previews and setting copies aside.

- Exact duplicates and visually similar images with matching dimensions.
- JPEG, PNG, WebP, TIFF, BMP and GIF; optional subfolder scanning.
- Group navigation and EXIF-oriented previews.
- Custom destination folder and verified moves without overwriting files.
- Batch processing of exact duplicates: keep the newest file, shortest name or longest name.
- French/English interface and manuals, cancellable processing and local move log.

**Windows:** download `Twins-1.0.0.exe` below. Python is not required.

Discarded copies are moved without re-encoding. Visual similarity requires review and does not prove file identity. Moves have no automatic undo. Runs locally without an account or data collection.
