TWINS — VERSION À TESTER / TEST VERSION 1.0.0

FRANÇAIS
1. Extraire tout le ZIP dans un même dossier.
2. Python 3.10 ou plus récent et Pillow sont nécessaires.
   Si besoin, dans le terminal : py -m pip install Pillow
3. Double-cliquer sur Lancer_Twins.cmd.
   Ou ouvrir EigrutelTwins.py dans VS Code, puis lancer depuis son dossier :
   py EigrutelTwins.py

Garder tous les fichiers ensemble : les modules twins_*.py sont nécessaires.
Il n'est pas nécessaire de construire un EXE pour tester.

Premier essai : utiliser un dossier contenant des copies de quelques images,
dont deux fichiers identiques. Choisir ce dossier et cliquer sur Analyser.
Vérifier les aperçus, FR/EN, le bouton i, puis le déplacement d'un doublon.
Le bouton Changer permet de choisir le dossier de destination.
Les fichiers sont réellement déplacés. Il n'y a pas d'annulation automatique ;
il est possible de les remettre à leur emplacement depuis le dossier Doublons.
Images proches compare uniquement des images de même définition après
orientation EXIF. Une ressemblance n'est pas une preuve de doublon.

ENGLISH
Extract the whole ZIP into one folder. Requires Python 3.10+ and Pillow.
Install Pillow if needed: py -m pip install Pillow
Double-click Lancer_Twins.cmd or run: py EigrutelTwins.py
Keep all supplied files together. No EXE build is required for this test.
Start with copies of a few images, including an identical pair. Choose the
folder and Scan. Check previews, FR/EN, help, then move one duplicate.
Files are actually moved. There is no automatic undo; restore them manually
from the destination folder if needed. Similar-image detection compares only
images with the same dimensions after EXIF orientation; review them visually.
